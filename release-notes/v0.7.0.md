# v0.7.0 — Skill 支持

> 本次带来**全新能力：Skill（技能）**——让 AI 拥有一套可复用、可扩展的"专业技能包"。
> 同时窗口管理更贴心（默认打开 + 记住位置/大小/网址），并修复了几处稳定性问题。

---

## ✨ 新增

### Skill 支持（对齐 Claude Code）

**什么是 Skill**：一份带元数据的 Markdown 说明书（`SKILL.md`），告诉 AI"某类任务该怎么做"。
AI 平时只看到技能的**名称和简介**，当任务相关时才加载**全文**——省 Token，又能让 AI
掌握你积累的专业流程。

**怎么用**（纯文件，无需界面操作）：

1. 在项目里创建 `.cuckoo/skills/<技能名>/SKILL.md`，或用户级 `~/.cuckoo/skills/<技能名>/SKILL.md`
2. 文件开头写元数据（YAML frontmatter）：

```markdown
---
name: code-review
description: 对代码变更做系统性审查。当用户要求审查代码时使用。
---

（这里写技能正文：让 AI 遵循的步骤、规范、检查清单……）
```

3. 技能还可带脚本（放 `scripts/`），AI 用现有命令工具运行

**兼容 Claude Code**：技能格式对齐 Claude Code / Agent Skills 开放标准，
从 Claude 生态搬来的技能可直接使用。

**刷新技能**：新增技能后，在设置面板点「发送skill信息」按钮即可让 AI 感知。

### 窗口默认打开（多选）

窗口管理面板里，每个窗口左侧新增「默认」复选框。勾选后，**下次启动自动打开这些窗口**（可多选）。
一个都没勾时，仍按老逻辑打开上次活跃的窗口。

### 记住窗口大小 / 位置 / 最后网址

关闭窗口时，自动记录它的大小、位置（含是否最大化）和**最后访问的网址**。
下次打开时按记录恢复——不用每次重新摆位置、重新找会话。

### 沙箱内可用 sleep

AI 在工具代码里可直接 `await sleep(毫秒)` 等待（如等页面加载、等操作生效），
此前会因沙箱没有计时器而失败。

## 🔧 改进

- **换行符处理更智能**：编辑文件时自动适配文件的换行风格（LF / CRLF），
  混合换行的文件会被统一。跨行替换更稳。
- **MCP 使用更规范**：明确要求 AI 调用 MCP 工具前先查询参数，减少"参数写错"类失败。
- **技能 / MCP 引导**：当你需要某个技能或 MCP 时，AI 会主动提示你去安装。

---

## 🐛 修复

- **长会话压缩失败**：修复"消息必须成对"导致的压缩失败（涉及重新生成过内容的会话）。
- **设置面板无法滚动**：内容较多时被裁掉，现可正常滚动。
- **glob / grep 空路径报错**：AI 传空路径时不再报错，按默认目录搜索。

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.7.0.exe`（安装版）或 portable 版。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.6.x 用户：本版支持自动更新，启动后稍等即可收到提示；也可到「帮助 → 检查更新」。
