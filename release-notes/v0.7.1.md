# v0.7.1 — 修复版

> 小版本修复：解决几个按钮「假成功」提示、MCP 使用提示更通用，并新增地址栏下方的对话 token 显示。

---

## 🐛 修复

- **按钮「假成功」提示**：「发送skill信息」「卡住了?点我」「沉浸式交流」「生成文档」
  这几个按钮，之前即使消息没真正发出去，也会弹「已发送」。
  原因是内部漏了 `await`。修复后：发不出去会如实提示失败。

- **MCP 使用提示更通用**：不再硬编码某个 MCP 的用法，改为通用规则——
  「调用任何 MCP 工具前，必须先查询它的参数」。对所有 MCP server 都适用。

---

## ✨ 新增

- **地址栏下方显示对话 Token**：地址栏和 AI 页面之间新增一条状态条，
  实时显示当前对话累计消耗的 token（过万显示为「x.xx 万」）。
  > 此功能为首次引入，欢迎反馈。

---

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.7.1.exe`（安装版）或 portable 版。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.7.0 用户：本版支持自动更新，启动后稍等即可收到提示；也可到「帮助 → 检查更新」。
