## ⚠️ DSH 插件兼容（实验性，未完成）

> **本项目前仍处于早期开发阶段，功能未完全完成，存在大量已知问题与未知缺陷。**
> 请把它当作**实验性功能**看待——可尝鲜、可反馈，但**不要依赖它处理重要任务**。

对标 DeepSeek 官方 Agent 框架 DSH（DeepSeek Harness）——**不依赖任何 DSH 代码**，Cuckoo 自己实现同名 API（"转接头"），目标让 DSH 生态的插件**原样**在 Cuckoo 里装、跑、用：

- **安装/运行（可用但脆弱）**：npm 下载 + esbuild 打包（劫持 `@deepseek-ai/*` → Cuckoo shim）+ 注册到工具表 → AI 可调用
- **管理 UI**：插件页「DSH 插件（npm）」区块（安装/启停/卸载/打开目录）
- **"够用空接口"**：未实现的 DSH API 一律 stub（万能 Proxy）——**这也是缺陷来源之一**：stub 能保证"装得上、加载不报错"，但被真正调用时行为可能与 DSH 不一致甚至无效

### 已接真的能力（C1–C6，但均为简化实现）

| 期 | 内容 |
|---|---|
| **C1** | `ctx.settings/tools/sessions` 接入 Cuckoo 真能力（宿主能力注入）|
| **C2** | 最小 DSH 运行时（内存会话事件流 + 投影），`todo_write` append 真写、投影真读回 |
| **C3** | DSH 事件总线接真（`ctx.on/emit` 收 Cuckoo 事件：流式/回复/工具/空闲）|
| **C4** | `ctx.systemPrompt.section` / `ctx.fs` / `ctx.agents` 接真（简化实现）|
| **C5** | 插件会话落盘（JSONL）+ 启动重放（lazily build）|
| **C6** | `ctx.skills/commands/goals/compaction/workspaceFiles/sessionTitle/tokenMeter` 接真 |

### 已知未完成 / 局限（摘自需求档案「未完成」）

- **大量 DSH API 仍是 stub**：仅"装得上"，被真实调用时行为可能不符预期
- **简化实现与 DSH 有差距**：`ctx.fs`（去掉版本/观察/沙箱）、`ctx.agents`（无 agent registry，用会话映射近似）、`ctx.sessionProjections`（不做 checkpoint/watermark/change feed）
- **P2 未做**：TS 转译、依赖解析（esbuild 已处理部分）
- **P3 未做**：UI / 命令 / 主题等 DSH 客户端能力
- **对照测试未固化**：`scripts/compare-dsh.mjs` 尚未回归化
- **仅少量插件真机验证**：`greet-tool`、官方 `@deepseek-ai/dsh-tool-todo` 验证通过，**其余插件兼容性未知**

> 遇到问题时欢迎反馈，但请知悉：**这是实验性功能，稳定性不作保证。**

## 💬 ChatGPT 登录态完整适配

此前 ChatGPT 只有简版 hook，登录态下有两个致命问题，本次一并修复：

- **收不到回复**：登录态 SSE 增量帧是裸 `{v:[...]}` 数组（无 `o` 字段），旧解析只认 `o:'patch'` → 正文全丢；且内部帧也带 `finished_successfully` → 空回复被误判 error。现重写为完整版，对齐 DeepSeek 契约：终态三态、流静默看门狗、HTTP 错误与限流识别、tokenUsage/msgIds 上报、XHR 拦截。
- **发不出消息**：ProseMirror 会把 `ClipboardEvent('paste')` 识别为"粘贴的文件"附件 → 改用 `execCommand('insertText')`；发送按钮空输入时不存在 → 走主进程 `sendInputEvent` 派发真实 Enter。
- **Google OAuth 登录**：补全 Chrome 客户端提示请求头（Sec-CH-UA*）与 `navigator.userAgentData` / `webdriver` 指纹修正，修复判定"内嵌浏览器不安全"拒绝登录。
- **修复**：`extractSessionId` 只认完整 UUID —— 此前会把中间态 `local-chatgpt` 当真实会话 ID，导致初始化后 GPT 拿不到项目目录。

（**@yangjh888**，PR #47）
