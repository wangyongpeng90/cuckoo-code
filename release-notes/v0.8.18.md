# v0.8.18 — DSH 插件生态打通 + 壳页面全面 React 化

本次大版本包含以下亮点：

1. **DSH 插件兼容能力大幅扩展** —— 从"能跑 demo"到"能装、能管、能热更新"；新增插件安装器、插件管理器面板、HMR、图标/设计令牌兼容层、CLI 命令 shim。发布 [DSH API 覆盖度清单](https://github.com/wangyongpeng90/cuckoo-code/blob/master/docs/dsh-api-coverage.md)（119 个 Context 服务，已实现 32 个）。
2. **壳页面全面 React 化** —— 13 个页面（工作区/窗口/文件/代理/设置/飞书/Token/对话/快捷词/关于/技能/MCP/插件）全部迁移到 React，设置页重做为居中模态（左导航 + 右内容 + 自动保存）。
3. **会话 ID 生命周期修复** —— 彻底废除 `local-xxx` 临时 ID，修复压缩上下文后新会话目录丢失、跨窗口对话错乱、插件按 profile 拉起窗口/打开对话定位错误等一整套问题。
4. **AI 回复拦截可配置** —— 设置新增「AI 回复拦截」分类，支持自定义正则列表（每行一条，任意命中即拦截）+ 提示语配置。空列表 = 不拦截。
5. **捐赠页** —— 关于页和 Token 页各展示一份捐赠区块，可通过壹基金捐赠支持本项目。

## 🧩 DSH 插件兼容

### 插件安装与管理

- **DSH Profile 安装器**：`pnpm` 打包 + manifest 同步 + patch 生成 + 单测覆盖
- **插件管理器面板**：main 插槽 + remote RPC + events + Switch/renderSlot + toast，支持安装/卸载/启停
- **HMR（热更新）**：插件启用/禁用立即生效，只重载被切的插件，不必重启
- **安装进度反馈**：`install-state` / `install-log` 事件流，pnpm 流式输出转发
- **不兼容包黑名单** + remote 单例化 + on 共享化 + 组件栈诊断

### DSH 界面兼容

- **设计令牌兼容层**：从 DSH `ui-theme` 提取 237 个 `--dsw-*` 变量（MIT 声明），外观自动对齐 Cuckoo 风格
- **图标兼容层**：252 个 DSH 真图标（从 `ui-primitives` 几何提取，Cuckoo 自实现渲染，MIT 声明）
- **DSH client 运行时**：`__ModuleLoader__` + `ctx.slots` + `ctx.plugin` + `ctx.get(服务名)` 全部真跑

### 其他 DSH 兼容

- **CLI 命令 shim**：拦截 `dsh plugin` 命令（esbuild 打包），`profileContext` + store 统一
- **inspect 真检查**：查 npm registry，拒绝非 bundle / 不存在的包
- **UI 插槽完善**：`toEntry` 对齐 DSH `StoredEntry`（小组件/component），`renderSlot` 支持 opts（only / entryKey）、`t` 注入
- **Modal/Menu 修 createPortal**：弹窗不再偏移

### DSH API 覆盖度清单（新增文档）

发布 [docs/dsh-api-coverage.md](https://github.com/wangyongpeng90/cuckoo-code/blob/master/docs/dsh-api-coverage.md)：对照 DSH 官方源码自动提取 119 个 Context 服务，标注当前实现状态（32 个已实现 / 87 个未实现），作为后续适配新插件的路线图。

## 🔧 会话生命周期修复

### 彻底废除 `local-xxx` 临时 ID

此前窗口创建时立即生成一个 `local-xxx` 临时 ID 并落库，导致：

- 数据库堆积大量 `web_id=null` 的垃圾记录
- 压缩/新建时反复复用旧 `logicId`，产生"父子指向自己"的死循环数据
- 内存 `currentSessionId` 与真实 URL 脱节，极难排查

**本次改动**：

- **没发消息 = 没会话**：窗口创建时不生成任何临时 ID，不落库
- **无 `webId` 页面 = 无当前会话**：首页 / 分享页 / settings 等页面立刻清空 `currentSessionId`
- **有 `webId` 才落库**：发消息产生真实 `webId` 后，通过 `ensureLogicId(webId)` 创建记录
- **加号纯导航**：壳页面 / 工作区 / 纯净模式的「+」只做 `loadURL(homeUrl)`，不再重置任何状态

### 压缩上下文修复

- **压缩后新会话目录丢失**：`selectProjectDir` 加 `isCompaction` 参数，压缩场景强制写 `pendingProjectDir`，不写旧逻辑 ID
- **父子指向自己**：`setSessionLineage` 按 `web_id` 匹配父会话，不再产生死循环数据

### 窗口定位修复

- **插件按 profile 拉起窗口**：`cuckoo-host` 的 `navigateWindowToHome` / `sendUserMessage` 按 `profileId` 找不到窗口时主动拉起，不再回退到"最后一个已打开的窗口"
- **打开对话跨窗口跳转**：`navigate-session` 按 `logicId` 查归属 `profile_id`，目标窗口未打开时主动拉起再导航

### 弹窗修复

- **子代理窗口不弹初始化遮罩**：子代理自己通过 `initProject(noDialog=true)` 初始化
- **非会话非主页 URL 不弹窗**：`/settings` / `/share/xxx` 等页面不再误弹

## ⚙️ AI 回复拦截可配置

新增设置分类「**AI 回复拦截**」：

- **正则列表**：每行一条，任意命中即视为 XML 工具调用（默认 4 条，和原硬编码行为一致）
- **提示语可配**：拦截命中后发给 AI 的提示文本
- **空列表 = 不拦截**：删掉全部规则后，XML 不再被拦截（当普通文本处理）
- **非法正则校验**：保存时提前报错，不等到运行崩溃
