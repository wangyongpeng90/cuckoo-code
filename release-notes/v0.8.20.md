# v0.8.20 — AI 用量统计与更稳健的浏览器 UA

本次亮点速览：

1. **AI 用量统计图表**（新功能）—— 设置页新增「用量统计」，直观呈现每天/时/分的发送量、回复量与 Token 消耗趋势，支持自定义时间范围和按窗口（Profile）筛选。
2. **统一 UA 版本**（@jiangchengnay，PR #71）—— 设置全局 `app.userAgentFallback` 为干净 Chrome UA，消除壳页面/Service Worker 与 AI 页面的 UA 不一致（不再暴露 Electron 标识），降低环境风控风险。
3. **全平台感知 UA 生成** —— 修复 PR #71 中硬编码 Windows 的问题，macOS/Linux 用户现在会得到与自身平台匹配的真实 UA 与 Client Hints。

> 特别感谢本版的外部贡献者：**@jiangchengnay**（PR #71 UA 统一）。

---

## 📊 AI 用量统计图表（新功能）

在「设置 → 用量统计」中，您可以直观看到：
- **发送数**（蓝色曲线）：您发送给 AI 的消息数量。
- **回复数**（绿色曲线）：AI 成功回复的数量。
- **消耗 Token**（黄色曲线）：精确到每次对话实际消耗的上下文 Token 差值（目前仅 DeepSeek 支持）。

支持 **按天 / 按时 / 按分** 聚合切换，支持自定义 **起始时间与结束时间**，支持按 **窗口（Profile）** 过滤。

（所有打点数据均存储于本地 SQLite 数据库，不上传云端，完全隐私安全）

---

## 🛡️ UA 统一与平台感知

**统一 UA 版本**（**@jiangchengnay**，PR #71）：修复了壳页面、Service Worker 等子资源暴露 `Electron/44.x.x` 标识的问题。现在所有 WebContents 均使用干净、一致的 Chrome UA。

**全平台感知**：修复了原方案在 macOS/Linux 上会伪装成 Windows 的问题。新版本会根据 `process.platform` 自动返回 Chromium 源码的编译期冻结常量（如 macOS 返回 `Macintosh; Intel Mac OS X 10_15_7`），并同步更新 Client Hints（`sec-ch-ua-platform` 等），大幅提升 OAuth 登录和环境识别的成功率。

## ⚠️ 安装说明

- **Windows**：下载 `cuckoo-code-win-v0.8.20.exe`（安装版，支持自动更新）
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）

> 已有 0.8.x 用户：启动后稍等会收到自动更新提示；也可到「关于 → 检查更新」。
