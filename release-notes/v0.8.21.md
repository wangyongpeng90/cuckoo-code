# v0.8.21 — 工具输出全面拟人化，文案模板可自定义

本次亮点速览：

1. **工具输出全面口语化** —— `read` / `write` / `glob` / `edit` 的返回值不再有 `<path>`、`<content>` 这类 XML 标签，改成人话。例如读文件首行从 `<path>a.txt</path><type>file</type>` 变成「a.txt 一共 20 行，内容如下」。
2. **文案模板完全可配**（11 个池）—— 工具结果回传文案、脚本标题模板、「让 AI 继续」提示词、各类工具结尾语全部可以自己改，每个池预置 4~1000 条随机取用。
3. **跨窗口共享设置** —— 这些配置统一存进本地 SQLite，开多个窗口改一次全部生效。
4. **pwsh 编码修复** —— 修复 PowerShell 读写文件时的中文乱码（含 BOM 处理），Windows 用户体验显著改善。

## ✍️ 工具输出全面口语化

`read` / `write` / `glob` / `edit` 的输出都去掉了 XML 标签，改为自然语言：

```
旧：<path>README.md</path>
    <type>file</type>
    <content>
    1: # 标题
    ...
    (End of file - total 50 lines)
    </content>

新：README.md 一共 50 行，内容如下

    1: # 标题
    ...
    (已到文件末尾，共 50 行)
```

`edit` 的多匹配报错还会附上具体行号，方便定位：

```
旧：oldString 在文件中出现 3 次。若要全部替换，请设置 replaceAll: true...
新：oldString 在文件中出现 3 次（第 5、12、20 行）。若要全部替换，请设置 replaceAll: true...
```

## 🎨 文案模板完全可配

设置页新增多个模板池分类，每个池一行一条，随机取用：

| 分类 | 池 | 条数 |
|---|---|---|
| 工具结果回复语 | 消息开头 | 1000 |
| | 脚本标题模板 | 1000 |
| 文件读取格式 | 完整文件首行 | 100 |
| | 部分读取首行 | 100 |
| | 读完整个文件结尾 | 8 |
| | 未读完结尾 | 6 |
| | 字节超限结尾 | 4 |
| 文件搜索格式 | 未截断结尾 | 7 |
| | 截断结尾 | 50 |
| 文件写入格式 | 新建文件 | 50 |
| | 覆盖更新 | 8 |
| 失败自动重试 | 「让 AI 继续」提示词 | 1000 |

支持占位符替换：`{path}` 文件路径、`{n}` 脚本总数、`{i}` 序号、`{r}` 成功/失败、`{start}`/`{end}`/`{total}`/`{rest}`/`{next}` 行号信息。

**跨窗口共享**：这些配置统一存进本地 SQLite（`cuckoo.db` 的 `meta` 表），所有窗口读同一份，改一次全部生效。

**未自定义的池**自动跟随代码内置默认值更新；自定义过的保留用户内容，不被代码升级覆盖。

## 🛠️ pwsh 编码修复

之前用 `pwsh` 工具读写中文文件会乱码：

- `Get-Content` 读 UTF-8 文件 → 中文变 `涓枃娴嬭瘯`
- `Set-Content` 写中文 → 我们的 `read` 工具读回来是 `??????`

**原因**：Windows PowerShell 5.1 默认按 ANSI/GBK 读写文件。

**修复**：自动给 `Get-Content` / `Set-Content` / `Out-File` / `Add-Content` 补 `-Encoding UTF8`，并在 `read` 工具里剥离开头的 BOM（PowerShell 5.1 写 UTF-8 必带 BOM）。工具描述也会提示 AI「优先用无 BOM 的写法」。

## 📝 其他改进

- **发送延迟默认值**：从 2-4 秒改为 10-20 秒（降低风控概率）。可在「设置 → 发送延迟」中调整。
- **去掉关闭窗口确认弹框**：点关闭直接关闭，不再弹「确定要关闭窗口吗」。
- **文件树节点上限**：5000 → 50000，大项目不再被截断。
- **工具描述收归一处**：以前一个工具的说明在系统提示词里出现三次（类型定义、使用指导、工具列表），现在统一到 `apiMetas`，提示词体积减少约 2KB。
- **头部文案池去除应答式前缀**：之前以「行，」「好，」「嗯，」开头的文案可能被 AI 误认为用户在回答它的问题，现已全部替换为「刚才」「这次」「这轮」等非应答式前缀。

## ⚠️ 安装说明

- **Windows**：下载 `cuckoo-code-win-v0.8.21.exe`（安装版，支持自动更新）
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）

> 已有 0.8.x 用户：启动后稍等会收到自动更新提示；也可到「关于 → 检查更新」。

**关于已自定义配置的说明**：如果你在旧版本中手动改过文案池，升级后会保留你的设置（不会被新版覆盖）。如果想使用新版内置默认值，在设置页对应池点「清空」或「填入内置默认」即可。
