# v0.8.22 — 真粘贴、UA 自洽、DeepSeek 新版流式适配

本次亮点速览：

1. **DeepSeek 提示词改用「真实系统粘贴」** —— 不再是程序化写输入框，而是主进程真的按了一次 Ctrl+V（`isTrusted=true`），事件层面与真人无差别；剪贴板只占用 10~30ms 就还原，你复制的东西不会被弄丢。
2. **UA 与客户端提示终于自洽** —— 之前是「JS 说自己是 Chrome，请求头说自己是 Chromium」，两边打架；现在 `userAgent` / `navigator.userAgentData` / `sec-ch-ua` 由同一份数据生成。
3. **DeepSeek 新版流式协议适配** —— 上游把 SSE 改成「片段全量快照」后，旧逻辑拿不到正文（正文恒为 0、被误判失败）；本次修复，思考与正文重新分离。
4. **启动更抗环境** —— IDE 终端带来的 `ELECTRON_RUN_AS_NODE` 会被自动剔除；源码运行时若仓库内 electron 起不来，会自动换用用户目录的副本启动。

## 🎯 DeepSeek 发送：改成「真实粘贴」

之前是把提示词「写」进输入框（原生 setter + input 事件），事件是合成的（`isTrusted=false`），部分站点一行代码就能识别。

现在走真系统粘贴：

```
主进程：clipboard.writeText(提示词) → webContents.paste() → 16ms 后比对并还原剪贴板
渲染层：全选输入框（粘贴替换选区）→ 触发粘贴 → 不做内容校验
```

- **占用窗口极短**：`paste()` 是同步派发，Chromium 当场把剪贴板数据快照进渲染进程，之后立刻还原；
- **不污染剪贴板**：多格式快照（text / html / rtf / image / bookmark）备份后写回；若你在这几十毫秒内自己复制了新内容，会检测到并**跳过还原**，不覆盖你的东西；
- **全局串行**：剪贴板是进程级资源，多窗口并发粘贴会排队执行，避免交错备份/还原；
- **长文本照常工作**：DeepSeek 会把超长粘贴自动转成 `.txt` 附件，这属于站点行为，我们不再判失败、也不会再补写一遍正文。

> 发送时序也一并调整：工具结果现在是「**先等随机延迟 → 再粘贴 → 等 600ms → 发送**」。延迟期间输入框保持干净。

## 🌐 UA 与客户端提示统一

之前的问题（实测）：

```
navigator.userAgent         → Chrome/152  ✅
navigator.userAgentData     → Google Chrome 152（页面里伪造的）
真实请求头 sec-ch-ua        → "Not?A_Brand";v="24", "Chromium";v="152"   ❌ 没有 Google Chrome
```

任何做一致性校验的站点（Google 登录、Cloudflare 等）都能一眼看出这是伪装。

现在改为**主进程 CDP** 下发（`Emulation.setUserAgentOverride`）——这是唯一能真正改写客户端提示请求头的方式：

```
sec-ch-ua            → "Google Chrome";v="152", "Not?A_Brand";v="24", "Chromium";v="152"
userAgentData.brands → 同上（完全一致）
platformVersion      → 19.0.0（本机 Windows 11 的真实值，不再是写死的 10.0.0）
```

覆盖范围：AI 主视图、`window.open` 弹窗（如 OAuth 登录窗）、工具创建的浏览器窗口。调试想要 DevTools 时可设 `CUCKOO_UA_OVERRIDE=off` 关闭。

## 🛰️ DeepSeek 新版 SSE 适配

上游把流式协议改成「片段全量快照」后，表现为：**思考内容正常、正文永远是 0 字**，最终被判为失败。

根因：新流用 `{"p":"response/fragments","v":[...]}`（SET，没有 `o`）下发片段数组，旧逻辑只认 `o = "APPEND"`，整帧被丢弃 → 片段类型一直停留在最初的 `THINK` → 之后所有无路径的增量都被当成思考。

修复：遇到片段数组时按全量快照重建片段类型与正文（幂等，不重复累计），思考与正文重新分开。实测同一条回复：`正文 232 字 / 思考 110 字`，日志显示「收到完整回复，长度=232」。

顺带加了诊断：hook 会保留最近 12 个原始帧，出错时随错误详情上报，以后再遇到协议变化不必重新挂探针。

## ⚙️ 其他改进

- **启动更抗环境**：自动剔除 `ELECTRON_RUN_AS_NODE`（VS Code / JetBrains 终端会带，导致 Electron 以 Node 模式闪退）；源码运行时若仓库内 `electron` 起不来（环境拦截），自动镜像到 `%LOCALAPPDATA%\cuckoo-electron\<版本>` 并用它启动。
- **初始化提示不再重复写入**：之前会出现「先粘贴成附件、又被写一遍正文」的双份问题，已修。
- **剪贴板占用有日志**：每次借用会打印实际毫秒数，方便排查。
