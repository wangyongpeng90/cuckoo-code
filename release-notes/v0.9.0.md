# v0.9.0 — 界面改版（ChatGPT 风格浅色壳）

> 本次是**界面整体改版**：原来的"覆盖层 + 悬浮球"不见了，取而代之的是一套浅色壳式界面——
> 左侧图标栏、可展开侧面板、顶部地址栏，AI 网页以圆角卡片嵌在右侧。

---

## ✨ 新增

### 全新浅色界面 · 0.9.0

- **左侧图标栏**：主页 / 会话 / 窗口 / MCP / 任务 / 设置 / 项目，点图标展开对应侧面板，再点收起
- **顶部地址栏**：显示/复制 URL、前进后退刷新；token 徽章显示当前会话上下文用量，点击直达「项目」面板的用量区
- **侧面板**：原覆盖层里的所有面板（会话、窗口管理、MCP、设置、项目、工具历史）全部搬进侧栏
- **任务面板**：命令执行状态、结果和历史记录在这里看，点击条目展开详情
- **平台选择页**同步改为浅色主题，视觉上与主界面一致

### 快捷键 · 0.9.0

- **Ctrl+Shift+C**：折叠/展开侧面板（再次展开时回到上次打开的面板）
- **Esc**：收起侧面板（面板已关闭时 Esc 仍归页面自己）

---

## 🔧 改进

- **设置改为全局共享** · 0.9.0：设置从各窗口页面 localStorage 迁到主进程 `settings.json`，
  所有窗口共用同一份；改一处，处处生效。
- **多窗口迁移取值规则** · 0.9.0：首次启动迁移时，若多个窗口（profile）各自存过设置，
  以**最先完成迁移的那个窗口**的值为准，其余窗口的旧设置不再保留。

---

## 🗑 移除

- **覆盖层面板与悬浮球**：全部功能已迁入左侧栏（上面说的图标栏 + 面板）
- **沉浸式交流模式**：随覆盖层一并删除

---

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.9.0.exe`（安装版）或 portable 版。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.8.x 用户：本版支持自动更新，启动后稍等即可收到提示；也可到「帮助 → 检查更新」。
>
> **注意**：升级后旧窗口里的个性化设置会迁移为全局共享设置（见上文取值规则），这是正常的。
