# v0.9.2 — Cuko 提示词瘦身 + 可视化编辑

> 这一版只动了 Cuko 的系统提示词：把原来 189 行的大段说明换成一份更朴素的版本，
> 并在设置里加了**可视化编辑**入口 —— 不用再改代码、重新打包，直接在界面上改。

本次亮点速览：

1. **系统提示词大幅瘦身** —— 189 行 → 66 行，去掉重复的规则宣讲，保留运行必需的占位符。
2. **设置里可直接编辑** —— Cuko 设置左侧新增「系统提示词」页签，改完即存。
3. **随时可回退** —— 「填入内置模板」看原始版本，「恢复内置」一键回到 `src/prompt/cuko.md`。

## ✍️ 提示词瘦身

原来 `src/prompt/cuko.md` 有一大段「身份与能力 / 核心原则 / 工具使用规则 / 输出前自查清单 /
执行流程示例 / 多步任务示例 / 错误处理 / 禁忌」。这些内容和 `{{TOOL_API_TYPES}}` 里的类型声明、
以及各工具自带的 doc 有大量重叠。

新版改成更朴素的写法：

- 用「背景说明」讲清楚运行环境（一个 js 窗口 + 结果框 + 目录选择）
- 保留工具契约：TypeScript 签名照旧完整注入
- 保留全部运行必需的占位符

行数从 **189 → 66**。

### 保留的占位符（全部正常替换）

| 占位符 | 内容 |
|---|---|
| `{{PLATFORM_INFO}}` | 操作系统与 bash/pwsh 差异 |
| `{{TOOL_API_TYPES}}` | `src/tools/api.d.ts` 完整类型声明 |
| `{{MCP_SECTION}}` | 已配置的 MCP server 与使用流程 |
| `{{SKILLS_SECTION}}` | 扫描到的技能 |
| `{{AGENTS_SECTION}}` | 扫描到的子代理 |
| `{{PROJECT_RULES_SECTION}}` | 无 paths 的项目规则 |
| `{{PROJECT_INTRO_SECTION}}` | 项目 `.cuckoo/CUCKOO.md` |
| `{{PROJECT_DIR}}` | 当前工作区路径 |

### 去掉了两个占位符

- **`{{TOOL_SECTIONS}}`** —— 各工具在代码里声明的时间接 doc（`toolRegistry.getFormattedPromptSections()`）
  加上 DSH 插件注册的提示词段。去掉后，模型仍能从 `{{TOOL_API_TYPES}}` 拿到完整函数签名，
  但不再有额外的使用说明文字。如果发现调用参数容易出错，可以在设置里把它加回去。
- **`{{MEMORY_SECTION}}`** —— 这个占位符在代码里本来就没有对应的替换逻辑（只有
  `default.md` / `claude.md` / `chatgpt.md` 里还留着），属于顺带清理，去掉不影响任何行为。

> **注意**：这次只改 Cuko。`default.md`、`deepseek.md`、`chatgpt.md`、`claude.md`
> 全部保持原样，主界面各平台不受影响。

## ⚙️ 设置里直接编辑提示词

Cuko 设置左侧导航新增**「系统提示词」**页签：

```
Cuko API
系统提示词    ← 新增
外观
网络安全
```

- **固定针对 Cuko**，不需要选平台（主设置页那个版本要选 provider，这里不用）。
- 进入页签即自动加载：有自定义就显示自定义内容，没有就显示内置模板供参考。
- 三个操作：
  - **填入内置模板** —— 把 `cuko.md` 原文填进编辑框（仅预览，不落库）
  - **恢复内置** —— 删除自定义，回到使用 `src/prompt/cuko.md`
  - **保存** —— 写入本地数据库
- 改动即时生效，**不用改代码、不用重新打包**。

### 生效优先级

```
0) 你在设置里保存的自定义内容   ← 最高
1) provider.getPromptTemplate()
2) src/prompt/cuko.md           ← 内置兜底
3) src/prompt/default.md
```

保存后会覆盖内置模板，点「恢复内置」即可回退。

### 关于占位符

编辑框里的 `{{XXX}}` 是发送时自动替换的，**请勿删除**——
删掉对应章节就不会出现在提示词里了。页面说明里也有这句提醒。

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.9.2.exe`（安装版，支持自动更新）。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。
- 安装前建议先退出旧版本；覆盖安装即可，配置与会话数据保存在本地数据库中。

> **升级提示**：本次没有破坏性配置变更，直接覆盖安装即可。
> 提示词改动只影响 Cuko 窗口，主界面各平台不受影响。
