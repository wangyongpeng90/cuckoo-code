# v0.9.4 — Cuko 消息排队与插话

> 这一版主要让 Cuko 窗口更好用：AI 回复的时候也能接着发消息（先排队，也能插话）；
> 新用户打开就是 Cuko 窗口；没选项目目录、没选模型时不再「默默失败」，而是弹窗告诉你怎么办。

本次亮点速览：

1. **消息发送队列** —— AI 回复中也能继续发，消息进输入框上方的排队区，本次运行结束后依次发出。
2. **插话** —— 点排队消息的 ↑，它会插进正在进行的这一轮，和工具结果一起发给 AI；不想插了点「将插话 ×」取消。
3. **启动只打开 Cuko 窗口** —— 没勾过「默认打开」的用户（包括新用户）启动后直接进入 Cuko，不再先弹选择平台页。
4. **没选项目目录时的默认工作区** —— 发送前弹窗让你选目录或用默认目录，保证 AI 拿到系统提示词、知道怎么调用工具。
5. **没有可用模型时弹窗** —— 不再只在聊天里插一条 ⚠️，而是弹窗带「去设置模型」按钮。

## 📨 消息发送队列与插话

AI 正在回复时，输入框右边**同时显示发送和停止两个按钮**。这时发出的消息不会被拦下，而是进入输入框上方的排队区：

```
2 条排队消息   本轮结束后依次发送 · 点 ↑ 插话              ˅
帮我再检查一下测试                              ✏️  🗑️  ↑
顺便更新 README              [将插话 ×]         ✏️  🗑️  ↑
```

- **普通排队**：按 Enter 或点发送就进普通排队，等本次运行**全部结束**（包括中间所有工具轮次）后依次发出。
- **插话**：点某条的 ↑，它变成蓝色的「将插话 ×」。
  - 本轮 AI 调了工具：工具执行完后，插话和工具结果一起发给 AI，不打断当前回复。
  - 本轮 AI 没调工具：这一轮写完后马上发出，中间不停。
  - 点「将插话 ×」取消，放回普通排队的最前面。
- **编辑 / 删除**：✏️ 原地修改（Enter 保存、Shift+Enter 换行、Esc 取消），🗑️ 删除；标题可以折叠。
- **停止**：排队消息不会丢，标题旁显示「已暂停」。点某条的 ↑ 立即发出这一条并恢复队列，或者直接发一条新消息也会恢复。
- **关掉窗口照样发**：队列放在主进程里，关掉 Cuko 窗口后，排队消息照常按顺序发出。
- **每个会话各有一份队列**，切换会话互不影响。

**目前的限制**

- 回复中发**带附件**的消息会提示「回复中暂不支持附件排队」，消息退回输入框，等这一轮结束再发。
- Ctrl+Shift+Enter 和 Enter 一样进普通排队；插话只能点排队区的 ↑。
- 队列只在内存里，**程序重启后清空**。

## 🪟 启动只打开 Cuko 窗口

- **勾过「默认打开」的网页版窗口**：和以前一样照常打开，Cuko 窗口随后在后台打开，不抢焦点。
- **一个都没勾（包括新用户）**：只打开 Cuko 窗口并放在最前面，**不再弹出选择平台页**。
- Cuko 左下角新增 **「🌐 打开网页版窗口」**：已经有网页版窗口就把它调到前面；没有就打开上次用过的那个。
- 再次双击程序图标（或 macOS 点 Dock）时，如果没有网页版窗口，会打开 / 聚焦 Cuko 窗口。
- 只开着 Cuko 窗口时，关掉它程序正常退出。

## 📁 没选项目目录时：默认工作区

**以前的问题**：会话没绑定项目目录时，第一条消息不会带上系统提示词，AI 不知道有 `cuckoo` 工具可用，之后再选目录也补不回来。

**现在**：发送时当前会话没有项目目录，会弹出「没有选择项目目录」：

- **选择项目目录…**：选一个文件夹，自动加进左侧工作区列表，绑定到这个会话后发送。
- **使用默认目录并发送**：弹窗里会显示完整路径；第一次使用时以「默认工作区」的名字加进工作区列表。
- **取消 / × / Esc**：不发送，输入框里的文字和附件都还在。

默认目录的位置：

| 情况 | 路径 |
|---|---|
| Windows 安装版 | `<安装目录>\cuko-default-workspace` |
| 安装目录写不进去（如装在 `C:\Program Files`） | `%APPDATA%\cuckoo-ai-pro-session\cuko-default-workspace` |
| macOS | `~/Library/Application Support/cuckoo-ai-pro-session/cuko-default-workspace` |

主进程也做了兜底：万一界面没拦住，发送前也会自动绑定默认目录，保证第一条消息带系统提示词。

## ⚙️ 没有可用模型时弹窗

以前没配模型、没选模型、模型被删、密钥解不开时，聊天里只多一条 ⚠️ 消息，不知道去哪儿改。现在会弹出「需要先设置模型」：

- 写明原因（还没配置任何模型 / 当前会话没选模型 / 选的模型已被删除 / 提供商不存在 / 密钥读不出来）
- **去设置模型**：直接打开设置的「Cuko API」页
- **取消**：消息留在输入框里；设置好后按一次发送就行（不会自动发出）

顺带修了一个问题：会话建立时还没配模型，配好后发送仍然报「尚未选择模型」。现在发送时会用当前选中的模型补上。

- **添加工作区后与选择工作区一致**：添加新工作区后会切换当前会话的项目并刷新左侧列表。

## ⚠️ 升级注意

- **启动行为变了**：没勾过「默认打开」的用户，升级后启动只会看到 Cuko 窗口。要用网页版（DeepSeek / Claude / ChatGPT 等），点 Cuko 左下角的「🌐 打开网页版窗口」；想每次启动都打开某个网页版窗口，在窗口列表里勾上「默认打开」即可。
- **默认工作区放在安装目录下**：卸载或重新安装时可能被一起删除，重要文件请放到你自己的项目目录。
- 升级前已经在「没选项目目录」状态下发过消息的旧会话，补不回系统提示词，建议新建会话。
- 没有破坏性配置变更，直接覆盖安装即可。

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.9.4.exe`（安装版，支持自动更新）。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。
- 安装前建议先退出旧版本；覆盖安装即可，配置与会话数据保存在本地数据库中。
